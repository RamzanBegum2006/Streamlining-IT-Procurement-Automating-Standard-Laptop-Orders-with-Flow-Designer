# Streamlining-IT-Procurement-Automating-Standard-Laptop-Orders-with-Flow-Designer
The project focuses on streamlining the IT procurement process for standard laptop orders using ServiceNow Flow Designer. The automated workflow creates a Catalog Task after the service request is approved and assigns the task to the Hardware group for configuration.
